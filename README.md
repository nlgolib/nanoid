# nanoid

nanoid is a Go implementation of the nanoid library.

## Installation

```bash
go get github.com/nlgolib/nanoid
```

## Functionality Highlights

- [x] Generate Nanoid with custom alphabet and size
- [x] Generate Nanoid without alike characters (1lI0Oouv5Ss)
- [x] Generate safe Nanoid (length 21), which is proofed to be collision free
